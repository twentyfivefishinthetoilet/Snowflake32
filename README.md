# Snowflake32
an ESP32-S3 devboard created for Hack Club's [Holiday Hardware Swap](https://swap.hackclub.com/). program it with the .ino file in /firmware and watch snowflakes fall on your board!
<img width="850" height="650" alt="snowflake32logo" src="https://github.com/user-attachments/assets/a1357eac-f6b7-4064-ba76-a5303f15d4e0" />

## features
- MICRO SD/TF CARD slot (spi)
- BATTERY CHARGING MODULE + IMPLEMENTATION
- EXTRA POWER PINS
- 3 CONTROLLED LEDS
- ESP32-S3-WROOM-1-N16R8 STUFF (wifi, BLE, 16mb flash and 8mb psram, etc.)
